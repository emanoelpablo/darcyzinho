# Darcyzinho

Assistente escolar do CETI Professor Darcy Araújo com perguntas frequentes, desafio de lógica e demonstração de empréstimos. O projeto usa HTML, CSS e JavaScript.

## Abrir no computador

Extraia os arquivos e abra `public/index.html` no navegador. Faça o teste de ditado pelo endereço HTTPS após a publicação, pois a disponibilidade do microfone e da voz depende do navegador e das permissões.

## Publicar na Vercel

1. Coloque o conteúdo deste projeto em um repositório Git.
2. Na Vercel, importe o repositório e use como raiz a pasta que contém `vercel.json`.
3. Publique com a configuração do arquivo `vercel.json`. A pasta de saída é `public` e o projeto não exige comando de build nem variáveis de ambiente na Vercel.
4. Abra o domínio de produção em uma janela anônima para conferir o acesso dos visitantes. Use o endereço confirmado para gerar o QR code.

## Conferir antes da apresentação

- Abra **Mais perguntas** e teste uma pergunta digitada e um dos atalhos.
- Na **Biblioteca digital**, empreste um exemplar, teste o bloqueio do segundo empréstimo e depois faça a devolução. Os títulos são fictícios.
- Complete o desafio de lógica e confira a pontuação.
- No aparelho do estande, teste o som e o ditado com perguntas fictícias.
- Confirme com a coordenação qualquer informação específica que pretenda acrescentar sobre grade, ingresso ou calendário. Para incluir trabalhos reais, utilize material da turma autorizado para publicação.

As respostas preparadas ficam em `public/app.js`. O site escolar usa voz do navegador. Para fixar o timbre em diferentes aparelhos, é possível gravar MP3 das respostas preparadas e vinculá-los ao botão de áudio.
